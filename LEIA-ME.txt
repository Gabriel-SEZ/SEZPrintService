SEZ PRINT SERVICE 0.4.7 — IMPRESSÃO AUTOMÁTICA A4 E 80mm
=========================================================

CORREÇÃO DO DIAGNÓSTICO DE INSTALAÇÃO
- O próprio Inno Setup cria service-install.log antes de executar o PowerShell.
- Registra identidade do instalador, pasta de destino, caminho do script e caminho do PowerShell.
- Confirma se install-service.ps1 existe.
- Registra o comando executado, se o PowerShell iniciou e o código de saída.
- O PowerShell recebe o caminho absoluto do log e acrescenta as etapas de validação, registro e inicialização.
- Se houver falha, o script consulta também os eventos recentes do Service Control Manager para tentar identificar a causa da inicialização.

LOGS
- Parada antes de atualizar: %ProgramData%\SmartEZ\SEZ Print Service\logs\upgrade-stop.log
- Registro do serviço: %ProgramData%\SmartEZ\SEZ Print Service\logs\service-install.log
- Execução do serviço: %ProgramData%\SmartEZ\SEZ Print Service\logs\AAAA-MM-DD.log

RUNTIME EMBARCADO
- Inclui Node.js 22.23.3 x64 e SumatraPDF 3.6.1 portáteis.
- Os hashes SHA-256 dos pacotes oficiais são conferidos durante o build.
- Não exige Node.js global ou download de runtime no computador.

SISTEMA
- Compatibilidade alvo: Windows 10 e Windows 11, 64 bits.
- Instala o SEZPrintService como serviço nativo do Windows.
- Inicialização automática pelo Windows, sem depender de login.
- Processo Node.js em segundo plano, supervisionado pelo host nativo C#.
- Reinício automático em caso de encerramento inesperado.
- Desinstalador remove o serviço Windows.

IMPRESSÃO
- Recebe documentos HTML reais do Smart EZ ERP pela rota local POST /api/print.
- Renderiza o HTML para PDF com Microsoft Edge ou Google Chrome em modo headless.
- Envia o PDF silenciosamente para a fila do Windows com SumatraPDF.
- Formatos suportados: A4 e bobina térmica 80mm.
- Mantém estilos, imagens, logos, fontes e referências relativas ao domínio Smart EZ.
- Processa trabalhos em fila para não sobrepor documentos.
- A resposta positiva confirma o envio ao spooler do Windows; não é sensor físico de saída do papel.

INSTALAÇÃO
1. Execute SEZ-Print-Service-Setup-0.4.7.exe como administrador.
2. Se já houver uma versão anterior, o Setup tentará pará-la antes de substituir o EXE.
3. O serviço SEZ Print Service será registrado e iniciado automaticamente.
4. No Smart EZ ERP, abra Configurações > SEZ Print Service.
5. Conecte, atualize as impressoras e salve a impressora A4 e a impressora 80mm.
6. Ative ou desative "Impressão automática silenciosa" conforme necessário.
7. Use os botões de teste A4 e 80mm antes de iniciar os atendimentos.
