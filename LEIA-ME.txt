SEZ PRINT SERVICE 0.4.4 — IMPRESSÃO AUTOMÁTICA A4 E 80mm
=========================================================

CORREÇÃO DO RUNTIME EMBARCADO
- O instalador inclui a distribuição completa Node.js 22.23.3 x64.
- Inclui node.exe, DLLs nativas e arquivos auxiliares que acompanham o ZIP oficial.
- Não copia apenas node.exe: dependências como OpenSSL/libuv permanecem junto ao executável.
- O build executa o node.exe a partir da pasta final runtime e confirma a versão.
- O pacote portátil SumatraPDF 3.6.1 também inclui os arquivos auxiliares encontrados junto ao EXE.
- Os hashes SHA-256 dos arquivos ZIP oficiais são conferidos antes de empacotar.
- O instalador não baixa nem instala runtimes no computador.

SISTEMA
- Compatibilidade alvo: Windows 10 e Windows 11, 64 bits.
- Instala o SEZPrintService como serviço nativo do Windows.
- Inicialização automática pelo Windows, sem depender de login.
- Processo Node.js em segundo plano, supervisionado pelo host nativo C#.
- Reinício automático em caso de encerramento inesperado.
- Log de instalação do serviço em %ProgramData%\SmartEZ\SEZ Print Service\logs\service-install.log.
- Logs de execução em %ProgramData%\SmartEZ\SEZ Print Service\logs.
- Desinstalador remove o serviço Windows.

IMPRESSÃO
- Recebe documentos HTML reais do Smart EZ ERP pela rota local POST /api/print.
- Renderiza o HTML para PDF com Microsoft Edge ou Google Chrome em modo headless.
- Envia o PDF silenciosamente para a fila do Windows com SumatraPDF.
- Formatos suportados: A4 e bobina térmica 80mm.
- Mantém estilos, imagens, logos, fontes e referências relativas ao domínio Smart EZ.
- Processa trabalhos em fila para não sobrepor documentos.
- A resposta positiva confirma o envio ao spooler do Windows; não é um sensor físico de saída do papel.

INSTALAÇÃO
1. Execute SEZ-Print-Service-Setup.exe como administrador.
2. O instalador copia o Node.js e SumatraPDF já incluídos no próprio EXE.
3. O serviço SEZ Print Service é registrado e iniciado automaticamente.
4. No Smart EZ ERP, abra Configurações > SEZ Print Service.
5. Conecte, atualize as impressoras e salve a impressora A4 e a impressora 80mm.
6. Ative ou desative "Impressão automática silenciosa" conforme necessário.
7. Use os botões de teste A4 e 80mm antes de iniciar os atendimentos.

REQUISITOS IMPORTANTES
- O computador precisa ter Microsoft Edge ou Google Chrome instalado em nível de máquina para renderização.
- Como o serviço roda como LocalSystem antes do login, filas e drivers precisam estar instalados para o computador/todos os usuários. Impressoras adicionadas somente ao perfil pessoal podem não aparecer.
- Instale drivers oficiais da impressora e confirme o tamanho de papel A4/80mm no driver do Windows.
- Não é necessário Node.js global nem internet para baixar runtime durante a instalação.
- Para verificar o estado do serviço, abra services.msc e localize SEZ Print Service.

DIAGNÓSTICO
- Falhas de registro do serviço: %ProgramData%\SmartEZ\SEZ Print Service\logs\service-install.log
- Logs de execução: %ProgramData%\SmartEZ\SEZ Print Service\logs\AAAA-MM-DD.log

BUILD
O EXE do instalador é gerado em Windows pelo GitHub Actions do repositório SEZPrintService.
O pipeline baixa os runtimes oficiais, confere os hashes SHA-256, inclui toda a distribuição Node.js e compila o host e instalador.
