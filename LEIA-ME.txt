SEZ PRINT SERVICE 0.4.6 — IMPRESSÃO AUTOMÁTICA A4 E 80mm
=========================================================

CORREÇÃO DO DIAGNÓSTICO DE ATUALIZAÇÃO
- O próprio Inno Setup cria %ProgramData%\SmartEZ\SEZ Print Service\logs\upgrade-stop.log antes de iniciar o PowerShell.
- Assim, o log é criado mesmo quando o PowerShell não inicia, quando prepare-update.ps1 não pode ser extraído ou quando o script falha antes de registrar sua primeira etapa.
- O instalador registra a extração do script, caminho temporário, existência do PowerShell, tentativa de execução e código de saída.
- O PowerShell também recebe o caminho absoluto do mesmo log e acrescenta detalhes da parada do serviço e dos processos residuais.
- Se a parada não for confirmada, o Setup cancela a atualização sem tentar substituir um executável bloqueado.

ATUALIZAÇÃO
- Antes de atualizar, o Setup interrompe o serviço Windows SEZPrintService.
- Aguarda o processo SEZPrintServiceHost.exe encerrar e liberar o arquivo.
- Se necessário, encerra somente um processo residual com esse nome, após tentar a parada normal do serviço.
- O serviço é registrado e iniciado novamente depois da cópia dos arquivos.
- Log de atualização: %ProgramData%\SmartEZ\SEZ Print Service\logs\upgrade-stop.log.
- Log do registro/inicialização: %ProgramData%\SmartEZ\SEZ Print Service\logs\service-install.log.

RUNTIME EMBARCADO
- Inclui Node.js 22.23.3 x64 e SumatraPDF 3.6.1 portáteis.
- Os hashes SHA-256 dos pacotes oficiais são conferidos durante o build.
- Não exige Node.js global ou download de runtime no computador.

SISTEMA
- Compatibilidade alvo: Windows 10 e Windows 11, 64 bits.
- Instala o SEZPrintService como serviço nativo do Windows.
- Inicialização automática pelo Windows, sem depender de login.
- Processo Node.js em segundo plano, supervisionado pelo host nativo C#.
- Reinício automático em caso de encerramento inesperado.
- Logs em %ProgramData%\SmartEZ\SEZ Print Service\logs.
- Desinstalador remove o serviço Windows.

IMPRESSÃO
- Recebe documentos HTML reais do Smart EZ ERP pela rota local POST /api/print.
- Renderiza o HTML para PDF com Microsoft Edge ou Google Chrome em modo headless.
- Envia o PDF silenciosamente para a fila do Windows com SumatraPDF.
- Formatos suportados: A4 e bobina térmica 80mm.
- Mantém estilos, imagens, logos, fontes e referências relativas ao domínio Smart EZ.
- Processa trabalhos em fila para não sobrepor documentos.
- A resposta positiva confirma o envio ao spooler do Windows; não é sensor físico de saída do papel.

INSTALAÇÃO
1. Execute SEZ-Print-Service-Setup-0.4.6.exe como administrador.
2. Se já houver uma versão anterior, o Setup tentará pará-la antes de substituir o EXE.
3. O serviço SEZ Print Service será registrado e iniciado automaticamente.
4. No Smart EZ ERP, abra Configurações > SEZ Print Service.
5. Conecte, atualize as impressoras e salve a impressora A4 e a impressora 80mm.
6. Ative ou desative "Impressão automática silenciosa" conforme necessário.
7. Use os botões de teste A4 e 80mm antes de iniciar os atendimentos.

DIAGNÓSTICO
Se a atualização falhar, envie:
%ProgramData%\SmartEZ\SEZ Print Service\logs\upgrade-stop.log

Se o registro do serviço falhar, envie:
%ProgramData%\SmartEZ\SEZ Print Service\logs\service-install.log
