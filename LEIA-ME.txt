SEZ PRINT SERVICE 0.3.0 — SERVIÇO NATIVO DO WINDOWS
==================================================

Compatibilidade alvo: Windows 10 e Windows 11, 64 bits.

COMPORTAMENTO
- Instala SEZPrintService como serviço nativo do Windows.
- Tipo de inicialização: Automático, executado pelo Windows durante a inicialização e antes do login do usuário.
- Conta: LocalSystem (sem depender de uma conta interativa).
- Processo Node.js executado oculto, sem janela de console.
- Se o processo Node.js encerrar, o host tenta iniciá-lo novamente após 5 segundos.
- O Gerenciador de Controle de Serviços do Windows também reinicia o host em falhas.
- Serviço pode ser iniciado, parado e reiniciado em services.msc.
- Logs em %ProgramData%\SmartEZ\SEZ Print Service\logs.
- Desinstalador remove o serviço antes de remover os arquivos.

IMPORTANTE SOBRE IMPRESSORAS
Como o serviço inicia antes do login e roda como LocalSystem, as filas e drivers de impressão precisam estar instalados para o computador (todos os usuários), não apenas no perfil de um usuário. Impressoras instaladas somente por usuário podem não aparecer. Isso é necessário para manter o serviço disponível antes do login.

INSTALAÇÃO E BUILD
O instalador é compilado no GitHub Actions:
1. Envie o conteúdo deste projeto para um repositório GitHub.
2. Abra Actions > Build SEZ Print Service installer > Run workflow.
3. Baixe o artefato SEZ-Print-Service-Setup-Windows-x64.
4. Execute o EXE como administrador.

O workflow compila service-host\SezPrintServiceHost.exe com o compilador C# do Windows e depois compila o instalador Inno Setup.

GERENCIAMENTO
- Abra services.msc.
- Localize “SEZ Print Service”.
- Use Iniciar, Parar ou Reiniciar.
- Tipo de inicialização: Automático.

TESTE NO ERP
1. Abra https://smartez.com.br.
2. Acesse Configurações > SEZ Print Service.
3. Conecte e atualize a lista de impressoras.
4. Escolha impressoras padrão A4 e 80mm e envie um teste.

LIMITAÇÕES
- Esta versão do motor lista impressoras Windows e envia teste textual. Não implementa impressão de documentos reais (OS, contratos, DANFE, recibos) por si só.
- O instalador precisa ser compilado pelo workflow para gerar o EXE 0.3.0. O EXE anterior não vira serviço nativo apenas pela atualização dos scripts.
- A primeira instalação do Node.js pode exigir internet.
- O instalador não remove Node.js na desinstalação, pois ele pode ser utilizado por outros programas.
- Não exponha a porta 32177 à rede; o servidor deve continuar restrito a 127.0.0.1.
