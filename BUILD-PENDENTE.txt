BUILD SEZ PRINT SERVICE 0.4.0
==============================

O projeto agora contém o motor de impressão de documentos HTML (print-engine.js), a rota POST /api/print, preparação de runtime Node.js/SumatraPDF e testes automatizados.
O pipeline GitHub Actions compila o host nativo Windows e o instalador Inno Setup.
O artefato SEZ-Print-Service-Setup-Windows-x64 é gerado após a execução bem-sucedida do workflow.
